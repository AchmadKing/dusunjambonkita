Integration Settings: PostgreSQL via Supabase

Hubungkan website ke database Supabase Cloud PostgreSQL secara real-time.

Unduh File PostgreSQL Schema (.sql)

Petunjuk Integrasi Supabase PostgreSQL:

  1. Buka Supabase Dashboard dan buat project baru.
  2. Buka menu SQL Editor di dashboard Supabase Anda.
  3. Salin isi file supabase_schema.sql yang telah kami sediakan lalu jalankan di SQL Editor untuk secara otomatis membuat seluruh tabel & kolom database PostgreSQL.
  4. Buka Project Settings > API di Supabase untuk mengambil Project URL dan anon public key.
  5. Masukkan kredensial ke form di atas lalu klik Simpan & Hubungkan Supabase.
